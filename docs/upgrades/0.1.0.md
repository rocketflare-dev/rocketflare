## What changed

The baseline. Everything in `docs/CONCEPTS.md` §§1–12 — tenancy, auth, the API shell, the database
and its inert RLS, jobs and realtime, email and storage, the UI shell, analytics, the AI layer,
deployment, the CLI and the shared contracts — plus the upgrade path in §13 that lets a copy of the
kit absorb everything that comes after this release.

That upgrade path is worth naming here, because every later note depends on it. A copy is detached
and renamed, so it never merges from the kit; instead `.rocketflare.json` records which release it
came from, the names it was renamed to, and a manifest of the parts that are meant to be replaced.
`scripts/upgrade.mjs` fetches the kit into a throwaway mirror, translates its diff into the copy's
own names, drops everything belonging to a part the copy deleted, and hands over the rest.
`/rf-upgrade` drives it, guided by notes like this one.

## How to apply

Nothing to apply. This is the release every other note chains back to, and the version a copy
carries in `.rocketflare.json` when it is made from the kit at 0.1.0.

If you are reading this in a copy made *before* 0.1.0 was tagged, there is one thing to do once:

```
node scripts/upgrade.mjs --adopt 0.1.0
```
